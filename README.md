# Экономика 2.0

ПО для работы с предметами и экономической средой проекта DoS.

## Принципы разработки

- Разработка постепенно, по отдельным модулям.
- Понятные названия и разделение ответственности модулей.
- Изменяемые параметры, коэффициенты, справочники и пути хранятся в настройках, а не зашиваются в код.
- Формулы и правила расчётов документируются по мере реализации.
- Каждый законченный этап фиксируется отдельным коммитом Git.

## Текущее состояние

Создан отдельный локальный Git-репозиторий. Основная ветка — `main`.
Язык, архитектура и первый модуль пока не выбраны.

## История и восстановление версий

Команды выполняются из папки `Economy 2.0`.

Посмотреть изменения и историю:

```sh
git status
git log --oneline
```

Сохранить законченный этап (перед коммитом проверить состав изменений):

```sh
git add README.md
git diff --cached
git commit -m "Описание изменений"
```

В `git add` указываются конкретные файлы текущего этапа.

Посмотреть старую версию в отдельной ветке, сохранив текущую историю
(сначала сохранить незакоммиченные изменения):

```sh
git switch -c inspect-old-version <commit>
```

Вернуться на основную ветку:

```sh
git switch main
```

Отменить конкретный коммит новым коммитом, сохранив историю:

```sh
git revert <commit>
```

`<commit>` — идентификатор коммита из `git log --oneline`.

Удалённый репозиторий `origin`: https://github.com/KirrieD/dos_economy_2.0

После коммита отправить сохранённые изменения на GitHub:

```sh
git push
```

Получить изменения с GitHub без автоматического создания merge-коммита:

```sh
git pull --ff-only
```
